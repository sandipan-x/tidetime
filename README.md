# TideTime

Tide height calculator: enter hours since high tide to get current tide state, next high/low times, a 24h curve, and fishing windows. Free tool.

## Features
- Live tide dial: current height, rising/falling state from hours since high water
- Next high/low time predictions with a 24-hour tide curve plot
- Tide-change fishing window finder for the next two tide turns
